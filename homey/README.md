# SENSY-ONE for Homey

AirBee is an ultra-low-power air quality sensor for Home Assistant and Homey Pro.
This app brings CO₂, temperature, humidity and air pressure to Homey through
Zigbee or Bluetooth LE, with Insights and Flow support. Measurements arrive
every five minutes.

Requires Homey Pro with software 13.4 or newer. Choose the device that matches
AirBee’s wireless mode. BLE requires Bluetooth advertisement reception.

See [AirBee setup and button controls](../README.md#getting-started).

## Install

1. On GitHub, click **Code → Download ZIP** and extract the entire ZIP.
2. Open the **homey** folder and double-click the installer for your computer:
   - **Mac:** [Install on Mac.command](<Install on Mac.command>)
   - **Windows:** [Install on Windows.cmd](<Install on Windows.cmd>)
3. Sign in with your Homey account if a browser opens. Return to the installer,
   choose your Homey with the arrow keys and press **Enter**. Wait for **Done!**

The installer downloads everything it needs automatically. You do not need to
install Node.js or type Terminal commands. Keep your computer and Homey on the
same local network, with internet access available during installation.

On Windows, extract the ZIP before starting the installer. On Mac, if macOS
blocks opening it, check **System Settings → Privacy & Security → Open Anyway**
for the installer you just downloaded.

You can close the installer after it finishes; the app stays installed on Homey.

To update, download the latest ZIP and run its installer again.
