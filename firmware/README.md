# AirBee Firmware

**Firmware: v1.0.1**

Download [AirBee-update.gbl](v1.0.1/AirBee-update.gbl) using **Download raw file**
on the file page. This is the signed Bluetooth update for AirBee.

Install it with Silicon Labs Simplicity Connect by following the
[firmware update instructions](../README.md#firmware-updates).

The [SHA-256 checksum](v1.0.1/SHA256SUMS) is included to verify the download.

For setup, button controls and pairing, see
[Getting Started](../README.md#getting-started).
